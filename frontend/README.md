# КАДР — фронтенд кинотеатра

Для запуска нужен Node.js. Из корня проекта выполни в PowerShell:

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

Открой адрес, который появится в терминале в строке `Local`.

Чтобы проверить выбор мест на демо-данных, открой «Последний поезд»,
выбери 14 ноября 2026 года и сеанс в 18:00.
